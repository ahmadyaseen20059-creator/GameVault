# GameVault 🎮

GameVault is a React-based web application that allows users to browse and manage a personal game library.

## Features
- Display a list of games.
- Search games by name.
- Sort games alphabetically.
- Navigation between Home, Login, Registration, and About pages.
- Responsive user interface.

## Technologies Used
- React
- JavaScript
- CSS
- Vite
- React Router

## How to Run the Project

1. Clone the repository:
   ```bash
   git clone https://github.com/ahmadyaseen20059-creator/GameVault.git
   ```

2. Open the project folder.

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```

5. Open the local URL shown in the terminal.
